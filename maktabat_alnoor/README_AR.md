# مكتبة النور — موقع متجر كتب عربي

واجهة RTL بتصميم أخضر داكن وذهبي، متجاوبة مع الهاتف والحاسوب، مع Flask + SQLite3 + JavaScript fetch APIs.

## تشغيل سريع على Windows
1. ثبّت Python 3.11 أو أحدث.
2. فك ضغط ZIP ثم افتح CMD داخل مجلد `maktabat_alnoor`.
3. أنشئ بيئة افتراضية:
   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   ```
4. ثبّت الحزم:
   ```bat
   pip install -r requirements.txt
   ```
5. انسخ `.env.example` إلى `.env`، وغيّر `SECRET_KEY` إلى قيمة عشوائية طويلة.
6. شغّل:
   ```bat
   python app.py
   ```
7. افتح `http://127.0.0.1:5000`.

## تشغيل على Android عبر Pydroid 3
- فك الضغط داخل مجلد يسهل الوصول إليه.
- افتح مجلد المشروع في Pydroid 3 وثبّت المتطلبات عبر الطرفية:
  `pip install -r requirements.txt`
- شغّل `app.py`، ثم افتح المتصفح على `http://127.0.0.1:5000` من الجهاز نفسه.
- قد تختلف طريقة الوصول إلى ملفات التخزين حسب إصدار Android وتطبيق فك الضغط.

## لوحة المدير
1. شغّل الموقع وافتح `http://127.0.0.1:5000/admin`.
2. أدخل اسم المدير `sashath` والرقم `7412580963` ورمز التحقق `71606`.
3. بعد الدخول يمكنك إضافة الكتب وإدارة الطلبات وتعديل النصوص والعبارات الإعلانية والشعار من إعدادات الموقع.
4. يمكن تغيير بيانات المدير من ملف `.env` عبر `ADMIN_NAME` و`ADMIN_NUMBER` و`ADMIN_CODE`، ثم إعادة تشغيل الخادم.

**مهم:** هذه بيانات دخول أولية طلبها صاحب المشروع. غيّر `ADMIN_CODE` و`SECRET_KEY` قبل أي نشر عام. رمز التحقق هنا ثابت ومحلي، وليس رمزاً يُرسل عبر WhatsApp.

## الكتب والمحتوى
- قاعدة البيانات تبدأ **من دون أي كتب افتراضية أو تجريبية**. ستبقى واجهة المتجر فارغة إلى أن تضيف كتبك بنفسك من لوحة الإدارة.
- العبارات الرئيسية والشعار النصي أو صورة الشعار وإعلان أعلى الموقع قابلة للتعديل من لوحة الإدارة.

## حالة الخصائص
- واجهة المتجر والسلة والبحث والأقسام: تعمل محلياً.
- تسجيل الدخول: OTP تجريبي يظهر في طرفية الخادم؛ لا يرسل واتساب فعلياً.
- الدفع: الطلب عند الاستلام تجريبي. شام كاش ورفع الإثبات غير مفعّلين.
- لوحة الإدارة: دخول خاص بالمدير، إدارة الكتب والطلبات والإحصائيات، وتعديل العبارات والشعار.
- الإعلانات العلوية قابلة للتحرير نصياً من لوحة المدير. إرسال WhatsApp الحقيقي، بوابة شام كاش، وCSRF والحماية الإنتاجية تحتاج إعداداً إضافياً قبل النشر.

**لا تنشر النسخة الحالية على الإنترنت كما هي.** راجع `API_DOCS.md` ونفّذ قائمة الأمان قبل الإنتاج.


## تحديث لوحة الإدارة
- لوحة الإدارة أصبحت مقسمة إلى قائمة جانبية وصفحة محتوى تتغير حسب القسم: نظرة عامة، الطلبات، الكتب، شام كاش، والشكل والعبارات.
- من قسم «شام كاش» يمكن تفعيل الطريقة وتعديل الاسم ورقم الحساب والملاحظة ورفع صورة الحساب/رمز QR من الجهاز أو استخدام رابط صورة.
- لا توجد كتب افتراضية؛ المتجر يبدأ فارغاً. كما تُحذف الكتب التجريبية المعروفة من الإصدارات القديمة عند بدء التطبيق.
- عند تفعيل شام كاش، تظهر بيانات التحويل للزبون وتُسجل الطلبات بحالة «مراجعة الدفع». هذه النسخة لا تتحقق تلقائياً من التحويل المصرفي.


## فصل لوحة الإدارة عن واجهة المتجر
- صفحة `/admin` مخصصة لإدارة المتجر فقط؛ لا يظهر فيها شريط تنقل المتجر العام أو أزرار «الرئيسية» و«الكتب» و«الأقسام» و«حسابي» أو تذييل المتجر.
- تتضمن قائمة الإدارة أقساماً مستقلة للطلبات، وإدارة الكتب، وإعدادات شام كاش، وتعديل الشعار والعبارات والإعلانات. قسم «إدارة الكتب» مخصص للمدير فقط وليس رابط تصفح عام.
- واجهة المتجر العامة تبقى متاحة للزبائن من الصفحة الرئيسية، بينما تعرض لوحة الإدارة أدوات التحكم بعد تسجيل دخول المدير.


## تحديثات الدفع وتتبع الطلب (الإصدار الحالي)
- صفحة إتمام الطلب تطلب اسم صاحب الطلب ورقم هاتف للتواصل. تُملأ الحقول تلقائياً من الحساب عند توفره ويمكن تعديلها للطلب.
- عند اختيار شام كاش يجب رفع صورة إثبات تحويل بصيغة PNG أو JPG أو WEBP، بحد أقصى 5 ميغابايت، ويمكن إضافة رقم العملية أو ملاحظة دفع.
- بعد تأكيد الطلب ينتقل المستخدم إلى `/track/<رقم الطلب>`، حيث يرى رقم الطلب وحالته وتفاصيله.
- حالات الطلب: قيد مراجعة الدفع، قيد التجهيز، قيد التوصيل، تم الاستلام. يستطيع المدير تغيير الحالة من لوحة الإدارة، ويشاهد المستخدم آخر حالة عند تحديث صفحة التتبع.
- الصور تحفظ في `static/uploads/payment_proofs/`. قبل النشر العام، ينبغي تقييد الوصول إلى إثباتات الدفع وحمايتها بسياسة صلاحيات مناسبة.
- قاعدة البيانات القديمة تتم ترقيتها بإضافة أعمدة الطلب الجديدة تلقائياً عند بدء التطبيق.
